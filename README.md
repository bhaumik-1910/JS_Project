# 🚀 JavaScript Mini Projects Collection 

This repository contains a **collection of beginner-friendly JavaScript mini projects** built to practice **core JavaScript concepts, DOM manipulation, and logic building**.

Each project is **independent** and can be run directly in the browser.

---

## 📁 Projects List

| No. | Project Name | Description |
|----|--------------|-------------|
| 1️⃣ | Color Changer | Change background colors dynamically using JavaScript |
| 2️⃣ | BMI Calculator | Calculate BMI based on height and weight |
| 3️⃣ | Digital Clock | Real-time digital clock using JavaScript |
| 4️⃣ | Guess The Number | Number guessing game with user interaction |
| 5️⃣ | Keyboard Codes | Display keyboard key codes on key press |
| 6️⃣ | Unlimited Color Change | Auto/random background color changer |
| 7️⃣ | Rock-Paper-Scissors | Classic Rock-Paper-Scissors game |
| 8️⃣ | Spotify Clone | Basic Spotify UI clone |
| 9️⃣ | Tic-Tac-Toe | Two-player Tic-Tac-Toe game |

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **VS Code Live Server**

## ⚙️ Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/bhaumik-1910/JS_Project.git
cd JS_Project
```

## ▶️ Project 1: Color Changer (Demo)

### 🔹 How to Run
1. Open the project folder:
```bash
cd "Project 1 Color Changer"
```

2. Open index.html in your browser OR use VS Code Live Server:
```bash
Right Click on index.html → Open with Live Server
```
